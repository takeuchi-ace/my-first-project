## 1. 年齢レーティング

アプリの実態：会話の選択、ゴルフのミニゲーム、道具の収集。
外部通信なし・広告なし・ユーザー投稿なし・課金なし・位置情報なし・実際の賭博なし。

| 設問 | 回答 |
|---|---|
| 暴力：漫画・ファンタジー | なし |
| 暴力：リアル | なし |
| 格闘 | なし |
| 恐怖・ホラー | なし |
| 性的表現・ヌード | なし |
| 冒とく的表現・下品なユーモア | **まれ／軽度** ※下記参照 |
| **アルコール・タバコ・薬物の使用または言及** | **まれ／軽度** ※下記参照 |
| 医療・治療情報 | なし |
| ギャンブル（模擬） | なし |
| ギャンブル（実際の賭博） | いいえ |
| コンテスト | なし |
| 無制限のWebアクセス | いいえ ※アプリ内ブラウザもリンクもない |
| ユーザー生成コンテンツの共有 | いいえ |
| ユーザーの現在地の共有 | いいえ |

**麺の細道は 4+ だったが、本アプリは上がる。**低く申告して差し戻されるほうが高くつくので、
下の2項目は正直に申告する。

### アルコールを「まれ／軽度」とする根拠

会話データ内の直接的な言及を機械集計した実測値:

| 語 | 件数 |
|---|---|
| 乾杯 | 15 |
| 酒 | 13 |
| ビール | 8 |
| 日本酒 | 4 |
| ウイスキー | 4 |
| ハイボール | 2 |
| ワイン | 1 |

いずれも会話の話題としての言及で、飲酒の描写・推奨・演出はない。
未成年の飲酒も、酩酊による有利不利もない。

### 冒とく的表現・下品なユーモアを「まれ／軽度」とする根拠

プレイヤーが選べる返事の中に、意図的にふざけた選択肢・失礼な選択肢が含まれる
（選ぶと相手の機嫌が下がる、という設計）。露骨な語句は含まないが、
「なし」と申告すると実物と食い違う可能性があるので「まれ／軽度」で出す。

### 注意

**年齢レーティングの設問はこの1年で作り直されている。**上の対応表は麺の細道（2026年8月）
時点の設問名。画面の文言が違っていたら、そちらに合わせる。
レーティングは審査対象のメタデータではないので、**審査中でも変更できる。**

## 2. プライバシー（App Privacy）

### 申告：**データを収集していません（Data Not Collected）**

### 根拠（コードを調査した結果）

| 確認項目 | 結果 |
|---|---|
| 外部への通信 | **なし**。`fetch` / `axios` / `XMLHttpRequest` / `WebSocket` がコードに存在しない |
| 解析・計測SDK | なし（Firebase / Sentry / Amplitude / GA いずれも未導入） |
| 広告SDK | なし |
| トラッキング | なし。`expo-tracking-transparency` 未導入、IDFA を取得しない |
| プッシュ通知 | **機能自体がない**（`expo-notifications` 未導入） |
| 端末識別子 | 取得しない |
| データの保存先 | 端末内の AsyncStorage のみ |
| 権限 | **要求する権限がない**。カメラ・位置情報・写真・連絡先・通知・ヘルスケアいずれも不使用 |
| 依存パッケージ | expo / react-native / react-navigation / react-native-svg / react-native-screens / react-native-safe-area-context / async-storage / expo-haptics / expo-screen-orientation / expo-status-bar / expo/metro-runtime |

Apple の「収集（collect）」の定義は**端末外へ送信すること**。本アプリは送信しないため
「収集していません」が正しい申告になる。

### 「トラッキング」の設問

「このアプリはトラッキングに使用されるデータを収集しますか？」→ **いいえ**

## 3. 輸出コンプライアンス

`app.json` に `ITSAppUsesNonExemptEncryption: false` を設定済み。
**ビルド 1 の Info.plist に埋め込まれていることを確認済み**（2026-09-15）。
独自の暗号化を実装しておらず、HTTPS通信すら行わないため、申告は「該当なし」。
通常は追加の設問が出ない。

## 4. 審査に関する情報（App Review Information）

### サインイン

**不要。**アカウント登録もログインもないので、デモ用アカウントは渡さない。

### 連絡先

麺の細道と同じでよい。**Apple からの連絡は Apple Account のアドレスに届く**ので、
この欄の宛先と実際の届き先は別物と思っておく。迷惑メールも見る。

### 審査メモ（備考欄）

```
本アプリは、接待ゴルフを題材にした会話選択式のフィクション作品です。
以下、審査のご参考まで。

・登場する人物・団体・企業・商談は、すべて架空のものです。実在の人物、
  団体、企業とは一切関係がありません。登場人物の肖像は、実在の人物を
  写したものではなく、本アプリのために制作した創作物です。

・現実の商習慣や贈答の実践を推奨・指南するものではありません。作中に
  登場する「道具」は、物語上の収集要素であり、実際の金銭の授受や
  取引は一切関係しません。

・アプリ内課金、広告、外部通信のいずれもありません。アカウント登録も
  不要です。端末内にゲームの進行状況を保存するのみで、データを外部へ
  送信しません。

・会話の中に酒類への言及が含まれるため、年齢レーティングの該当項目を
  申告しています。飲酒の描写や推奨はありません。

・実際の賭博、および賭博の模擬はありません。

ご不明な点がありましたら、お知らせください。
```

**この欄は日本語で書いてよい。**麺の細道でも日本語で通っている。

## 6. 想定される指摘と、その備え

### Guideline 2.1（情報要求）が来る可能性は高い

新規アプリの定番。麺の細道でも 8/14 に来た。
**却下ではなく差し戻しで、返信すれば審査が再開する。**件名だけで判断しない。
対処は `appstore-release` スキルの `reference/情報要求への回答.md` に従う。

### 題材そのものへの問い合わせ

「接待」「紹介」「契約」という語が並ぶので、**ビジネス実務アプリと誤読される**可能性がある。
その場合の答えは審査メモに書いた通り（フィクション、娯楽、実在しない）。
説明文の末尾にも同じ趣旨を明記してある。

### 年齢レーティングの再指定を求められた場合

レーティングは審査中でも変更できる。指定し直して返信すればよい。

### 実機で動かないと落ちる

Guideline 2.1（App Completeness）。**提出前に実機で一周する。**
特にパットのドラッグ操作は、ブラウザでは確認できない。
