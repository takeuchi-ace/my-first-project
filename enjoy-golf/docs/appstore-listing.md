## 説明文（4000字以内）

```
ゴルフの腕前は、あまり関係ありません。

「ENJOY GOLF QUEST」は、接待ゴルフの18ホールを、会話の選択だけで渡り切るゲームです。


■ 何をするゲームか

相手と一日ラウンドを回ります。
天気の話、仕事の話、昔の話。
ホールごとに場面が訪れて、あなたは並んだ返事から一つを選びます。

正解は相手ごとに違います。
沈黙を好む人がいます。踏み込まれたい人がいます。
褒められると警戒する人がいます。

選び続けると、相手の機嫌が動きます。
機嫌が動くと、相手のゴルフが変わります。


■ 相手を勝たせる

一日の終わりに、契約の話が出るかどうかが決まります。

条件のひとつは、相手がその日「いつもより良く回れたか」。
気分よく振れた人は、実際によく飛びます。

だから、あなたが上手い必要はありません。
それどころか、あなたが完璧に打つと機嫌を損ねる相手もいます。
自分が主役でいたい人の前では、外したほうがうまくいきます。


■ 21人

銀行の支店長。体育会系の社長。寡黙なプロ。老舗料亭の女将。政界のフィクサー。
それぞれに、好きな話題と、触れられたくない話題があります。

一人と契約すると、その人が次の誰かを紹介してくれます。
誰から始めるかで、道筋が変わります。


■ 道具

ラウンドを重ねると、持ち物が増えます。
レーザー距離計。貼るホッカイロ。塩キャンディー。胃薬（大瓶）。
銀行のロゴが入った、折りたたみ傘。

「こういう日に、これを持っていた人がいた」という条件で手に入ります。
全部で42。どれも、誰かの一日から出てきたものです。


■ 収録

・登場人物　21人
・場面　372
・選択肢　1,160
・道具　42


■ ご注意

登場する人物・団体・企業・商談は、すべて架空のものです。
実在の商習慣や贈答の実践を勧めるものではありません。

通信は行いません。アカウント登録も、アプリ内課金もありません。
```

## スクリーンショット

**iPhone 6.9インチ（1320×2868 または 1290×2796）が必須。**縦向き。
supportsTablet を false にしたので **iPad は不要**。

撮る場面の案（上から順に並べる）:

1. タイトル画面
2. 会話の場面（相手の顔と選択肢が三つ見えているところ）
3. ゲージが動いた直後（機嫌が変わったことが分かるところ）
4. スイングのミニゲーム
5. 結果画面（接待グレードと接待ポイント）
6. 契約成立の幻想画カットイン

**5枚目・6枚目は契約を取らないと出ない。**実機で一周する必要がある。

数値（接待ポイント・打数）が写り込むので、**撮ったあとコードと突き合わせる**。
麺の細道ではこのやり方で食い違いが複数見つかっている。
