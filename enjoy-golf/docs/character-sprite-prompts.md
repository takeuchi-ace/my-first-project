# キャラクター スプライトシート 生成指示書

全 21 キャラクター分のスプライトシートを画像生成 AI に作らせるための指示書。
田中・鬼塚を含めて全員作り直し、各キャラの個性を反映した **ゴルフウェア × 5感情 + 普段着 × 1（タイトル画面用）** の **6 フレーム構成**。

---

## 共通技術仕様（全キャラ共通・厳守）

```
- 画像サイズ: 1800 × 1024 px（横長）
- フレーム数: 6（横一列に等間隔で配置）
- 1フレーム当たり: 300 × 1024 px
- 背景: 完全透過（PNG, アルファチャンネル）
- 各ポートレイトはフレーム中央〜下寄りに配置
- ポートレイトの実視認領域: 約 250 × 400 px（フレーム内に余白を残す）
- スタイル: chibi（2.5〜3頭身）ピクセルアート / レトロゲーム風
- ピクセルくっきり、アンチエイリアスなし、ハードエッジ
- パレット: 鮮やか・色数控えめ（10〜12色程度）
- 影付け: 1〜2段階の単純なシェーディング
- 構図: 頭〜胸元のバストアップ、正面向き、左右対称（眼の高さは揃える）
- 6フレーム間でキャラの輪郭・髪型・髪色・肌色は完全に同一に保つ
```

## フレーム順（左 → 右）

6フレーム必ずこの順で並べる：

| 位置 | 用途 | 服装 | 表情の指針 |
|---|---|---|---|
| 1 | **best**（ゴルフ） | ゴルフウェア（キャラ専用） | ドヤ顔／全力の笑み。歯が見えるくらい大きく口開け、目は弧状に細める |
| 2 | **good**（ゴルフ） | ゴルフウェア（同上） | にこやか。普通の笑み、口角上げ、目は普通の開き |
| 3 | **neutral**（ゴルフ） | ゴルフウェア（同上） | 真顔。口は一文字、表情なし、視線まっすぐ |
| 4 | **bad**（ゴルフ） | ゴルフウェア（同上） | 不快・困り顔。口角下がる、眉間にシワ、目線わずかに伏せる |
| 5 | **worst**（ゴルフ） | ゴルフウェア（同上） | 怒り or 落胆。歯を食いしばる or 涙、眉が険しい、目つき鋭い |
| 6 | **title**（普段着） | キャラ固有の普段着／職業を象徴する服 | にこやか（good 相当）。タイトル・キャラ選択画面用の "決め顔" |

**重要**:
- フレーム 1〜5 はゴルフウェアで統一。**服装も完全に同一**、表情のみ変化。
- フレーム 6 は普段着。職業や性格を一目で表現する服装で、表情は perror に good 寄り（カタログ用の良い顔）。
- 髪型・髪色・肌色・髭・メガネなど顔まわりは 6 フレーム全て同一。

---

## キャラ別指示

各キャラを 1 プロンプトで生成。プロンプト末尾に必ず上記「共通技術仕様」と「フレーム順」を併記する。

ファイル名は `<英字キャラ名>_sheet.png` で保存し、`src/assets/sprites/` に配置。

## 生成後の組み込み手順

1. 生成された PNG を `src/assets/sprites/<charname>_sheet.png` に配置（既存の田中・鬼塚も上書き）

2. `src/faces/spriteSheets.ts` を **6 フレーム仕様に更新**：
   ```ts
   // 画像: 1800×1024px / 6フレーム → 1フレーム 300×1024
   const FRAME_W = 1800 / 6; // 300
   const FRAME_H = 1024;
   const FRAME_ORDER: Emotion[] = ['best', 'good', 'neutral', 'bad', 'worst'];
   // フレーム 6 はタイトル用（emotion 範囲外）

   // 全 21 キャラ分の登録
   SPRITE_SHEETS.set(<id>, {
     source: require('../assets/sprites/<charname>_sheet.png'),
     frameCount: 6,
     frameWidth: FRAME_W,
     frameHeight: FRAME_H,
     cropX: 0,
     cropY: 360,
     cropW: FRAME_W,
     cropH: FRAME_W,
     frameOrder: FRAME_ORDER,
   });
   ```

3. **タイトル/キャラ選択用 API を追加**：
   ```ts
   // 6 フレーム目（インデックス 5）を取得する公開関数
   export function getTitleFrame(charId: CharacterId): SpriteFrameRef | undefined { ... }
   ```

4. CharacterSelectScreen / HomeScreen の `<FaceSprite>` を、このタイトル用フレームを表示する新コンポーネント or プロップに切り替え

5. `src/faces/pixelAvatar/index.ts` の `TRAITS` を全削除（PNG が全キャラ揃うのでフォールバック不要に）

## 生成のコツ

- **6フレーム間でキャラの輪郭・髪型・服装の継続性を必ず明示**（5感情はゴルフウェアで完全同一、フレーム 6 のみ普段着に変更）
- 生成 AI が `1800×1024` の比率を守らない場合は「16:9 横長、横一列に6顔」と補足
- スタイルブレが出たら 田中・鬼塚 の既存シート画像を参考画像として渡す
- 透過背景に対応してない AI なら、白背景で出してから後処理で抜く
- 生成後、フレーム間の顔まわり（髪型・髪色・肌色・髭・メガネ）が完全に一致しているか必ず確認
